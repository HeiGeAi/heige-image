# 载体 → 设计默认 决策矩阵

**这张表是设计脑第二步（设计决策）的查表依据。** 用户没说的维度，按这里填有理由的默认，不留空、不反问。每个默认都带一句为什么，方便后面单变量改图时知道动哪一格。

**一句话用法**：先认载体（公众号封面 / 信息图 / 小红书组图 / 文章配图），落到对应行，先看「引擎 / 风格」列定走 render.py 版式还是 gen.py 插画，再把那一行的默认抄进 brief 的设计决策段，补一句「这张为什么偏离默认」（如果有偏离）。没有偏离就照抄。

## 先记三条全局铁律（所有载体共用）

**第一条：黑哥视觉签名分两套，按引擎走，别串。**

插画类（API 引擎 gen.py 出图）统一走粘土 3D 卡通，英文 prompt 前缀固定：

```
Clay 3D cartoon illustration, soft claymation texture, warm pink and cream color palette, rounded cute character design, gentle 3D rendering, healing cozy mood, clean off-white background, soft studio lighting, smooth matte clay surface.
```

版式类（无 key 引擎 render.py + HTML 模板出图）走 guizang 简约设计，干净留白、网格、克制、瑞士/编辑/杂志质感，对应新的 `templates/*-clean.html`。

配色情绪：插画走暖粉 + 奶油白，治愈温暖、圆润可爱；版式走干净中性底 + 一个克制强调色，大量留白。两套是 heige-image 的双签名，护城河三样之一。

**第二条：账号隔离红线。**
heige-image 是黑哥AI账号视角，插画用粘土 3D 卡通、版式用 guizang 简约，跟其他账号的视觉规则不串。别的内容线那套规则（比如案例文章的真实素材合规要求）不进 heige-image，生图产品只背自己这套签名。调用前先确认账号视角对得上。

**第三条：插画走 API 三个物理出图桶，版式走 HTML 模板。比例是「意图」不是「像素」。**
插画类走 OpenAI 兼容的 gpt-image 类模型，实际只吐三种分辨率，所有比例自动映射到最近的桶：

| 出图桶 | 像素 | 吃掉哪些常见比例 |
|---|---|---|
| 方 | 1024×1024 | 1:1 |
| 横 | 1536×1024 | 16:9、4:3、3:2、2.35:1、21:9 |
| 竖 | 1024×1536 | 3:4、9:16、2:3、4:5 |

**所以下面每行的「推荐比例」给的是构图意图，括号里标它实际落进哪个桶。** 想要 2.35:1 的电影封面，API 给你的是 1536×1024 的横图，构图时按宽幅排，别指望真出 2.35:1 的扁条。需要精确的窄幅版式、逐字精确的文字（标准公众号封面、长条信息图），那是版式图，走无 key 引擎 render.py 截 `templates/*-clean.html`，文字零变形、尺寸随便定，不受三桶限制。

文章配图不止章节图一种，按用途分四类。画面型走插画引擎粘土 3D，逐字精确的卡片型走版式引擎 guizang 简约，按这个分。

| 配图子类 | 引擎 / 风格 | 推荐比例（实际桶） | 文字层级 | 构图模板 | 用在哪 | 典型坑 |
|---|---|---|---|---|---|---|
| **章节场景图** | 插画 → gen.py（粘土 3D 卡通） | 16:9（横桶） | none / ≤30% | 单场景，角色 + 核心道具演出本章动作 | 每个 `##` 章节标题下方，喂完读率 | 退化成装饰；靠角色动作做到看图懂本章 |
| **概念对比图** | 插画 → gen.py（粘土 3D 卡通） | 16:9（横桶）或 1:1（方桶） | 少字，左右各一个标签 | 左右对置分区，中间留白分割，两侧各一个粘土角色/道具 | 讲「A 不行 B 行」「以前 vs 现在」 | 左右构图要平衡，对比物要一眼分清；标签字少，精确文字交给版式引擎 |
| **数据/金句卡** | 版式 → render.py `cover-clean.html`（guizang 简约） | 1:1（HTML 自定尺寸） | title 级一句金句大字，可带数字 | 单焦点居中，金句/数字用大字重排版，大量留白，细线点缀 | 文中要被截图转发的那句狠话 | 数字别让模型乱编，HTML 里写死即可零变形；金句 ≤14 字，留白别填满 |
| **流程/步骤图** | 版式 → render.py `infographic-clean.html`（guizang 简约） | 16:9 或竖 3:4（HTML 自定尺寸） | 少字，每步一个短标签 | 3-6 个节点连线，方向感（左→右或上→下），极简线性图标 | 讲操作流程、工作流、几步搞定 | 节点超 6 个必乱；步骤标签压成 2-4 字；箭头方向别拧 |

## 设计脑查表流程（第二步用这个）

1. **认载体**：用户说的或从需求 brief 的「载体」维度读出来。认不准就按主题猜，封面感（一句话钩子）走封面，要点多走信息图，种草向走小红书组图，给文章喂图走文章配图。
2. **定引擎**：照载体的「引擎 / 风格」列分流，逐字精确的版式（封面、信息图、金句卡、流程图）走 render.py 的 `*-clean.html`（guizang 简约），画面叙事的插画（章节图、小红书组图、对比图）走 gen.py（粘土 3D 卡通）。拿不准就看文字密不密：文字一多一精确就走版式。
3. **抄默认**：落到对应行，把默认（引擎 / 比例 / 风格 / 配色 / 文字层级 / 构图 / 坑）抄进设计决策。
4. **填偏离理由**：用户明确指定的维度覆盖默认，并写一句为什么偏离。没指定的全照默认，不反问。
5. **单轮自检**（不递归）：照下面 checklist 过一遍，过不了的就地修，修完不再回头死循环。

### 单轮 checklist

- [ ] 引擎选对了：版式走 render.py `*-clean.html`，插画走 gen.py，没用插画引擎硬出精确长文
- [ ] 比例选了；插画类标清落进哪个桶（方/横/竖）按桶形状排，版式类尺寸 HTML 自定即可
- [ ] 风格对路：插画是粘土 3D 卡通那一串前缀（暖粉 + 奶油白），版式是 guizang 简约，两套没串
- [ ] 配色 ≤3 色：插画暖粉 + 奶油白 + 米白底，版式中性底 + 一个克制强调色，留白当主角
- [ ] 文字层级跟载体匹配（封面 title-only、信息图 text-rich、章节图 none/极少），且字数在该载体上限内
- [ ] 逐字精确的文字走版式 HTML 截图零变形，没硬塞给 gen.py（gpt-image 类模型多字必崩）
- [ ] 小红书组图：首图当 --ref 锚住，安全区没压关键信息
- [ ] 插画靠角色动作把意思演清楚，不是纯装饰，做到看图懂；版式靠结构和留白把信息讲清
- [ ] 没超成本护栏（单组张数上限、回炉最多 1 轮）

## 各载体默认速记（懒人版）

记不住主表就记这四句，够用：

**公众号封面**：版式 guizang `cover-clean.html` + 宽幅 + 单焦点大留白 + ≤12 字大标题 + 一个克制强调色。
**信息图**：版式 guizang `infographic-clean.html` + 竖/方 + 模块化网格 + 三级文字 + ≤6 块每块一句话，文字零变形。
**小红书组图**：插画粘土 3D + 竖桶 + 首图钩子拉满（粘土角色当主角）+ 首图当锚锚住全组 + 避开顶右和底部安全区。
**文章配图**：插画粘土 3D + 横桶 16:9 + 每章一个角色场景 + 文字越少越稳 + 看图懂本章；金句卡/流程图改走版式引擎。
