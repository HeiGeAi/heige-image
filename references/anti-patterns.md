# 反 AI 体检清单 + 能力圈声明

这个产品自己就是 AI 生图工具，反 AI 让吐出来的图认得出是黑哥的，不是任何扩散模型随手吐的均值图。

文字稿那套反 AI 味的逻辑搬过来一样成立：**你越是 AI 高手，做出来的东西越不能让人一眼看出是 AI 做的。** 通用 AI 生图的问题跟通用 AI 写作一个病根，都在往中间值塌缩。生图塌缩成完美对称加塑料高光加居中构图加谁都画过的烂隐喻。黑哥靠两套定死的签名跳出均值：插画走粘土 3D 卡通（暖粉加奶油白、手工粘土哑光材质、粉白小机器人），版式走 guizang 简约设计（米白底、暖粉强调色、大留白、发丝线网格）。体检清单就是把塌缩点一条条拎出来，出图前压住，出图后回查。

---

## 一、反 AI 体检清单

分两段过。**出图前过 prompt，出图后过成品。** 两段都过完才算交付。

### 出图前体检（过 prompt 规格文件，落 prompts/NN-主题.md 时就查）

每条都是问句，答不上来或者答案踩雷就回去改 prompt，别先出图浪费额度。

**1. 隐喻有没有撞烂梗。**
灯泡代表创意、齿轮代表系统、发光大脑代表 AI、向上箭头代表增长，这些是扩散模型训练集里被喂烂的视觉口水话，出来就是一眼 AI。换成粉白小机器人带具体动作的场景。要做「帮你干活」就画机器人捧着文件夹招手，要做「搭积木」就画机器人在拼一面奶色积木墙。具体到能截图，抽象到只剩符号就是 AI 味。

**2. 构图干不干净。**
画面堆满杂物、元素挤到边、背景塞复杂场景，是 AI 生图的另一种崩法。粘土签名要的是干净米白背景 + 主角居中或黄金分割点 + 道具像气泡悬浮环绕 + 留足空白。prompt 里主动写 clean off-white background、minimal、floating elements with soft shadows，别让模型把画面填满。

**3. 配色有没有滑进莫兰迪和赛博蓝紫。**
低饱和灰调（莫兰迪）和蓝紫渐变发光（赛博朋克烂大街色）是 AI 生图两大投降色，谁的图都长一个样。黑哥的签名色是暖粉加奶油白，低饱和暖色治愈，压在暖粉 `#F5A8B8`、奶油白 `#FBF3EC`、米白 `#F6ECE4` 这一段。prompt 里把色板写死，别让模型自己挑色，更别让它滑去高饱和撞色或冷蓝紫。

**4. 质感是不是又是塑料 3D 渲染。**
默认那种圆润反光的 C4D 塑料感、强高光、磨皮干净到没有一粒灰，是 AI 生图的出厂设置，也是粘土签名最容易翻车的地方。粘土要的是哑光手工软陶质感（matte handmade plasticine）、细微指纹压痕、柔光软影、微弱次表面散射，绝不光滑反光、绝不金属。质感词写进 prompt 前缀，每张都带，负向里写死 no glossy plastic、no metal、no harsh highlights。

**5. 文字层级有没有越界。**
插画和概念图里文字占比压在 30% 以内，靠画面叙事。文字一多就暴露 API 生图的死穴（见下面能力圈），而且容易变成那种贴满标语的 AI 海报味。要精确排版的版式图这条管不住，那种活走 render.py 的 guizang 简约版式引擎，别硬塞给 API。

**6. 这张图换个主题还成不成立。**
prompt 写得太通用，换个标题照样能套，说明它没扎进这一篇的具体冲突，就是一张可替换的库存图。好的规格是这张只服务这一篇，invariant 清单写得出哪些必须锁死。

### 出图后体检（拿到成品图，贴出去之前查）

成品图肉眼过一遍，下面任意一条中招就回炉。**回炉最多 1 轮**，1 轮还不行就降级处理（换主体重写 prompt，或者老实承认这张不该用 API 做）。

**7. 手、字、对称物有没有崩。**
手指数量、文字拼写（尤其中文，扩散模型基本写不对）、左右本该对称的物件（耳机、眼睛、四肢），这三处是 AI 生图崩坏重灾区。崩了直接废，别将就贴。

**8. 有没有那股通用 AI 油光。**
说不清哪不对但就是觉得假、觉得腻、觉得在哪见过，多半是那股塑料高光加均值构图又回来了。粘土签名一旦滑成塑料反光就废，相信这个直觉，它跟读文字时那句"这读着像机器写的"是同一种警报。

**9. 黑哥签名认不认得出。**
盖掉一切上下文，单看这张图，认得出是黑哥这套粉白粘土治愈风吗？暖粉加奶油白、哑光软陶质感、粉白小机器人三样在不在？还是放进任何一个 AI 生图账号都不违和？认不出签名就是护城河没立住，这张图等于白做。

**10. 治愈劲到没到位。**
粘土卡通的命根子是治愈亲和。画面只是好看、只是把字面意思画出来，没有那层「想伸手摸一下、松一口气觉得这事不吓人」的劲，就退化成普通配图了。看图的人会不会觉得暖、觉得可爱，是这套画风的及格线。

### 一句话自检

出图前问：**这 prompt 是不是谁都能写出来？** 出图后问：**这张图盖掉标题还认得出是黑哥的粘土治愈风吗？** 两个都答得硬气，才算过检。

## 二、能力圈声明

诚实划边界。不阉割能做的，不夸大做不到的。两条引擎都已落地，下面说清楚各自能做什么、需要什么、不做什么。

### 现在能做什么

**插画 / 概念图 / 吉祥物示意图，走 API 引擎 gen.py，出粘土 3D 卡通。**

- 走 OpenAI 兼容的 gpt-image 类 API，自己配 base_url + key（官方、Azure、各家中转都行，国内可选 gptx.cc 这个渠道）。
- 配黑哥粘土签名：暖粉加奶油白配色、手工粘土哑光材质、粉白圆润小机器人吉祥物、柔光治愈、干净米白背景。
- 适合的活：公众号章节配图、16:9 总结图、治愈系概念图、吉祥物示意、不需要精确文字的画面。

**版式图（封面 / 信息图 / 卡片 / 流程图），走无 key 引擎 render.py，出 guizang 简约设计。**

- 选 `templates/*-clean.html` 模板→填真实数据→Playwright 截图，零 API、免费、中文一个像素不差。
- 配黑哥简约签名：暖米白底 + 单一暖粉强调色 + 大量留白 + 发丝线网格 + 越大越细的字号反差，瑞士 / 编辑杂志质感。
- 适合的活：要逐字精确文字的封面大标题、多级文字信息图、数据金句卡、流程步骤图。

**两条引擎共用设计脑三步**：需求翻译（大白话翻成 6 维 brief）、设计决策（查决策矩阵填有理由的默认值、定走哪条引擎）、编译 prompt 或填模板。每张插画先落 `prompts/NN-主题.md` 规格文件，可复现可改单变量；成本护栏只管 API 引擎（单次张数上限、回炉最多 1 轮），版式引擎免费不约束。

### 需要什么

- **API 引擎要一把能用的 key**（自己配 base_url + key，接任意 OpenAI 兼容 API，国内可选 gptx.cc 这个渠道）。没 key 设计脑前几步照跑，能交付规格文件，就是出不了插画图。规格先行这个机制刚好让没 key 时也有产出。
- **版式引擎要 Playwright + chromium**（`pip install playwright && playwright install chromium`），装一次到处用，不要 API key。

### 不做什么

**别拿 API 引擎硬出精确文字版式。** 扩散模型生图本质画的是像素，不是排版，文字稍长就拼错、字距乱、对不齐，中文尤其崩。封面大标题、信息图、卡片这类逐字精确的活交给 render.py 的 guizang 版式引擎，HTML/CSS 焊死版面，文字零变形。

**还有几条边界一并说清，免得踩坑当 bug 修：**

- **API 尺寸只有三种，别信十种比例。** API 层实际只出三种分辨率：方图 1024×1024、横图 1536×1024、竖图 1024×1536。脚本里那十种宽高比全部映射到这三种里去，写 21:9 跟写 16:9 出来的图一样大。要真正的超宽幅、要精确画幅比，走版式引擎在 CSS 里焊任意尺寸。
- **API 图里文字别指望写对。** 重申第 5 条体检，图里文字压在 30% 以内，且默认它可能拼错。需要可读、要正确的文字，走版式引擎。
- **不串别人的画风。** 这产品只出黑哥这两套签名（插画粘土 3D、版式 guizang 简约），都属于黑哥 AI 账号。别串其他账号的视觉（锋利吐槽、写实冷峻科技风那些），也废弃旧版波普拼贴讽刺。

### 一句话定位

**有 key 就能出粘土 3D 卡通插画，规格文件可复现可改；要逐字精确的版式图走无 key 的 guizang 简约引擎，免费且文字不崩。两条引擎同一套暖色域绑住，一眼认得出是黑哥。**
