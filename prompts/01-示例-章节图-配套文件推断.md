# 01-示例-章节图-配套文件推断

这是随仓库发布的示例规格，演示完整的规格文件格式。场景：用户说「给这篇教程的第三章配张图」，没点名任何画风，设计总监从配套文章推断出全部设计决策。

## Brief（7 维）

载体：文章章节图
受众：想用脚本偷懒的职场新手
主题：把每周重复的报表活儿交给一段脚本，人去干别的
情绪：轻松、鼓励
文字层级：none
比例：16:9
风格线索：用户没点名，待设计总监定

## 设计方案（设计总监产出，每项带来源等级）

画风：软萌 3D（库默认，理由：新手教程要降低门槛感，查风格库快查表「治愈亲和 × 章节图」命中）
色板：#8AB6A0 主 / #F3F0E8 底 / #E8C15A 强调（配套文件推断，理由：文章配的产品截图是低饱和绿色系界面，主色跟它走保持成套，强调色取暖黄做对比）
场景与构图：一个圆润小机器人坐在传送带起点整理一摞报表，传送带另一端的人类端着咖啡看窗外，横构图左右分置（配套文件推断，取自文中「你喝咖啡的时候脚本在跑」这句真实意象）
文字与排版：纯视觉零文字（载体默认，章节图靠画面叙事）
风险提示：无

## 最终 Prompt

```
Clay 3D render, matte handmade plasticine texture, soft sculpted rounded surfaces, chubby inflated volume. A cute rounded robot sitting at the start of a small conveyor belt, tidying a stack of paper reports; at the other end of the belt, a relaxed human figure holds a coffee mug and looks out a window. Horizontal left-right composition, generous negative space, clean warm off-white background. Color palette locked: sage green #8AB6A0 as primary, warm cream #F3F0E8 background, muted amber #E8C15A accent. Soft diffused studio lighting, warm ambient glow, gentle soft shadows, subtle subsurface scattering. Cinematic wide banner composition. No readable text anywhere. No glossy plastic, no metal, no harsh shadows, no high saturation, no watermark, no signature, no clutter.
```

## Invariant 清单（改图时必须逐条锁死）

- 色板：#8AB6A0 / #F3F0E8 / #E8C15A，三色不换不加
- 主体：圆润小机器人在传送带起点整理报表
- 配角：人类端咖啡看窗外，在传送带另一端
- 材质：哑光软陶、圆角无棱、柔光软影
- 文字：零文字

## 备注：用户点名画风时怎么写

用户如果开口就说「要水彩风」「用我们品牌蓝 #1E5AA8」，对应项的来源等级直接标「用户指定」，设计总监照办并只补剩下的缺口。示例：

```
画风：水彩手绘（用户指定）
色板：#1E5AA8 主（用户指定，品牌蓝）/ 底色与强调色由设计总监按水彩透明感补齐（库默认）
```

来源等级的意义在改图：标「用户指定」的项是硬约束，回炉重出时一个都不能动。
