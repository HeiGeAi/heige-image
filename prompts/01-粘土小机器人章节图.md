# 01-粘土小机器人章节图 · 把重复活儿交给脚本

## Brief（6 维）

载体：文章章节图
受众：AI 圈从业者 + 普通读者
主题：小机器人帮你把重复的活儿拆成几步交给脚本
情绪：治愈、轻松、亲和
文字层级：none（纯视觉，靠角色动作和道具叙事）
比例：16:9（横桶 1536×1024）

## 设计决策（查矩阵填，带理由）

抄「文章正文配图（章节图）」那一行的默认：

- **引擎 / 风格**：插画 → gen.py，粘土 3D 卡通。
- **推荐比例**：16:9 宽幅，实际落横桶 1536×1024，主角偏左、右侧道具悬浮留呼吸区。
- **配色倾向**：暖粉 `#F5A8B8` + 奶油白 `#FBF3EC` + 米白底 `#F6ECE4`，低饱和暖色治愈，奶黄积木做小面积点缀。
- **文字层级处理**：none 纯视觉。章节图默认就该靠画面叙事，文字留给正文，0 字最稳也最不踩中文糊字坑。
- **构图模板**：单场景，粉白小机器人当主角，对着一面悬浮的奶色积木墙比划，周围飘着齿轮、文件卡、勾选标记当氛围道具。
- **典型坑**：章节图最容易退化成「配字幕的装饰图」，靠小机器人的动作把「帮你搭好、帮你跑通」演清楚，做到看图懂本章；文字越少越稳。

## Invariant 清单（改图时必须逐条锁死）

- **主色**：暖粉 `#F5A8B8` + 奶油白 `#FBF3EC` + 米白底 `#F6ECE4`，奶黄做积木小点缀
- **主角**：粉白小机器人（奶油白圆身子、暖粉耳机、胸口暖粉爱心、深棕黑屏幕脸、笑眼、天线顶粉爱心、Q 版幼态比例）
- **动作**：站左侧，一只手向上比划一面悬浮的奶色积木墙（演「帮你搭好」）
- **氛围道具**：粘土齿轮 / 文件卡 / 气泡 / 勾选标记，圆角奶色，悬浮带柔影
- **材质**：哑光手工粘土、圆角无棱、柔软膨胀体积、柔光软影、微弱次表面散射，禁塑料反光禁金属
- **背景构图**：干净米白背景，主角偏左，道具悬浮右侧，大量留白
- **控字**：0 可读文字，0 中文，纯视觉
- **情绪**：治愈、温暖、亲和，看着想摸一下
